## What is Ahoy?

Ahoy is a brilliant little command-line tool that turns project chaos into organised workflows. Using simple YAML configuration files, you can create self-documenting CLI programs that your entire team can actually use and understand.

Think of it as your project's personal command centre - no coding required, no dependencies to worry about, just straightforward configuration that makes your development life easier.

Ahoy transforms complex commands like this:

```bash
docker-compose exec --user=82 web drush cache:rebuild --uri=https://example.com
```

Into this:

```bash
ahoy cr
```

Whether you're juggling a personal side project or wrestling with enterprise complexity, Ahoy cuts through the noise and makes your development process actually enjoyable.

## When Should You Use Ahoy?

Ahoy really shines when you're dealing with:

- **Team Consistency**: Everyone on your team can run the same commands the same way, no matter their setup
- **Complex Commands**: Those awful long commands with 15 flags that you always get wrong? Turn them into `ahoy deploy`
- **Project Documentation**: Instead of hunting through README files, your commands document themselves
- **Multiple Environments**: Different commands for dev, staging, and production without the confusion
- **New Team Members**: Instead of sending them a 20-page setup guide, they can just run `ahoy` and see exactly what's available
- **Containerised Environments**: Make Docker commands bearable for humans to use

## Key Benefits

### Zero-Code Configuration
Just write some YAML, and you're done! No programming skills needed - each command is simply declared with what it does and what it should run.

### Self-Documenting Commands
The best part? Every command you create automatically gets:
- Built-in help text and command listings when you run `ahoy`
- Tab completion (when set up)
- Usage instructions that your teammates will actually read

### Flexible & Powerful
- Works from any subdirectory in your project
- Handles environment variables like a champ
- Lets you import and override commands across multiple files
- Supports command aliases for those really useful shortcuts
