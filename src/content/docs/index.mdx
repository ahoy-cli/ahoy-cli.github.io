## About Ahoy

Ahoy turns the commands you run on a project into short, named commands that everyone on the team can use. You list them in an `.ahoy.yml` file, and Ahoy runs them from anywhere in the project, with help text and tab completion included.

So instead of typing this:

```bash
docker-compose exec --user=82 web drush cache:rebuild --uri=https://example.com
```

you type this:

```bash
ahoy cr
```

Ahoy is a single binary. It works with Docker, SSH, local scripts, or anything else you can run from a shell.

## Quick start

```bash
# Install (macOS)
brew install ahoy

# Add an .ahoy.yml full of example commands
cd my-project
ahoy config init

# See what's available
ahoy
```

The examples file has around 30 commands for Docker, testing, databases and Drupal. Keep the ones you want and delete the rest.
