Ahoy can tab-complete command names and aliases from your `.ahoy.yml` in Zsh and Bash.

## Zsh

Install the [ahoy-cli/zsh-ahoy](https://github.com/ahoy-cli/zsh-ahoy) plugin. Its README has instructions for Oh My Zsh, Antigen, zinit and manual installs.

Then open a new terminal, type `ahoy ` (with a space) and press Tab.

## Bash

1. Install bash-completion:

   <Tabs>
     <TabItem label="macOS">
       ```bash
       brew install bash-completion
       ```
     </TabItem>
     <TabItem label="Ubuntu / Debian">
       ```bash
       sudo apt install bash-completion
       ```
     </TabItem>
   </Tabs>

2. Generate the completion script and load it from your `.bashrc`:

   ```bash
   mkdir -p ~/.bash_completion.d
   ahoy --generate-bash-completion > ~/.bash_completion.d/ahoy
   echo '. ~/.bash_completion.d/ahoy' >> ~/.bashrc
   ```

3. Reload your config:

   ```bash
   source ~/.bashrc
   ```

## Check it works

Open a new terminal, type `ahoy ` and press Tab. You should see your commands and their aliases.

<Aside type="note">
  You'll only see project commands when you're inside a folder that has an `.ahoy.yml`, or inside
  one of its subfolders.
</Aside>
