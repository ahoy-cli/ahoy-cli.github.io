# Shell Autocompletion

Ahoy supports command autocompletion (tab completion) in both Zsh and Bash. Setting up shell autocompletion will make your Ahoy workflow faster and more efficient by:

- Allowing you to press tab to complete command names
- Showing available commands when you press tab after typing `ahoy `
- Completing command aliases as well as primary command names

## Setting Up Autocompletion

<Tabs>
  <TabItem label="Zsh"> <Badge text="v2.3.0+" variant="tip" size="small" />
    For Zsh users, there's a dedicated plugin available that provides robust completion support for Ahoy commands.

    <Steps>
      1. Visit the [ahoy-cli/zsh-ahoy](https://github.com/ahoy-cli/zsh-ahoy) repository
      
      2. Follow the installation instructions to add the plugin to your Zsh setup
      
      3. The plugin works with popular Zsh frameworks including:
         - Oh My Zsh
         - Antigen
         - zplug
         - zinit
         - And manual installation
    </Steps>

    <Aside type="tip">
      **Zsh Plugin Added in v2.3.0**: If you're using Oh My Zsh, you can add `zsh-ahoy` to your plugins list in your `.zshrc` file:
      ```bash
      plugins=(... zsh-ahoy)
      ```
    </Aside>
  </TabItem>

  <TabItem label="Bash">
    For Bash users, you'll need to make sure bash-completion is installed and properly set up.

    <Steps>
      1. Ensure bash-completion is installed on your system:
         ```bash
         # On Ubuntu/Debian
         sudo apt install bash-completion
         
         # On macOS with Homebrew
         brew install bash-completion
         ```
      
      2. Add the following to your `~/.bashrc` file (create it if it doesn't exist):
         ```bash
         if [ -f /etc/bash_completion ]; then
           . /etc/bash_completion
         fi
         ```
      
      3. Run the following command to get the Ahoy completion script and install it:
         ```bash
         mkdir -p ~/.bash_completion.d
         ahoy --generate-bash-completion > ~/.bash_completion.d/ahoy
         echo '. ~/.bash_completion.d/ahoy' >> ~/.bashrc
         ```
      
      4. Reload your shell configuration:
         ```bash
         source ~/.bashrc
         ```
    </Steps>

    <Aside type="caution">
      The exact location of the bash-completion file may vary depending on your Linux distribution or macOS setup. Adjust the paths accordingly.
    </Aside>
  </TabItem>
</Tabs>

## Testing Your Setup

After installing shell completion, you can test if it's working properly:

1. Open a new terminal window or reload your shell configuration
2. Type `ahoy ` (with a space at the end) and press Tab
3. You should see a list of available Ahoy commands
4. If you have configured aliases for commands, try typing the beginning of an alias and press Tab to see if it completes

## Troubleshooting

If autocompletion isn't working as expected, try these steps:

- Make sure Ahoy is properly installed and in your PATH
- Verify that your shell completion system is working (try other commands that have completion)
- Check that you've reloaded your shell configuration after setting up completion
- For Zsh users, ensure the zsh-ahoy plugin is correctly installed
- For Bash users, confirm the completion script was successfully generated and sourced

<Aside type="note">
  Shell completion will only show commands that are available in your current context. Make sure you're in a directory with an `.ahoy.yml` file, or one of its subdirectories, to see project-specific commands.
</Aside>
